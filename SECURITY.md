# Security Policy

## Supported versions

This project is in early development. Only the latest commit on `main` receives
fixes; there are no released versions yet.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/rlopc/jul-ia/security/advisories/new)
instead of opening a public report.

You can expect an acknowledgement within a week. If the report is accepted, the
fix and the advisory are published together.
